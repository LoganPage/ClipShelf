# Windows 1.4.0

本版本统一修复高 DPI 滚动验证与短滚动条把手的绘制问题。

- 修复 125% / 150% / 175% 等非整数缩放下，滚动探针因设备像素取整而在开始滚动前误判失败的问题。
- 主列表、预览与设置等所有滚动条统一采用真正参与 WPF 轨道布局的 24 DIP 最小可抓取高度。
- 修复记录较多时滚动条把手底端被裁成直角的问题，保持 5 DIP 可见宽度、3 DIP 圆角与原有颜色不变。
- 没有在缺少复现证据时加入首次滚动预热；滚动行为、虚拟化、记录选择和用户数据格式保持不变。

安装方式：下载并解压 `ClipShelf-Windows-v1.4.0-public-x64.zip`，运行 `ClipShelf/ClipShelf.exe`；也可以运行包内 `install.ps1` 覆盖安装。覆盖安装会保留现有历史记录和设置。

最低支持 Windows 10 2004，推荐 Windows 11。
