# Windows 1.3.8

- 新增历史记录类型筛选，并保持搜索、选择与滚动位置逻辑一致。
- 新增图片 OCR 文字提取与框选复制体验；处理无文字、取消和识别失败状态。
- 记忆主窗口尺寸与位置，并在显示器布局或 DPI 变化后安全回到可见区域。
- 完善高 DPI 下的布局测试容差、快速预览选择同步，以及自动更新资源名称兼容。
- Windows 10 2004 及更新版本，推荐 Windows 11；提供 x64 独立运行 ZIP，不需要单独安装 .NET。
