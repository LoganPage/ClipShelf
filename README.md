# ClipShelf for Windows

Windows 原生版本，基于 [LoganPage/ClipShelf](https://github.com/LoganPage/ClipShelf) 的 Swift 源码移植；沿用原版图标、列表布局、浅色/石墨深色和设置面板，选择及命令操作按 Windows 习惯适配。Mac 源码参考提交 `0ab74e8338b720409349b6f627de0d6d1f4013c5`。

## 使用

打开发布包中的 `ClipShelf/ClipShelf.exe`。独立运行包不需要另装 .NET。`install.ps1` 可安装到当前用户的 `%LOCALAPPDATA%\Programs\ClipShelf` 并创建桌面和开始菜单快捷方式，无需管理员权限。

- `Ctrl+Shift+V`：全局显示 ClipShelf，可在设置中修改，冲突时会提示。
- `↑/↓`：选择记录；记录上的 `Enter` 不执行命令。
- `Space`：快速预览文字记录、常见文本文件、图片、PDF、DOCX、PPTX 及 XLSX/XLSM 表格；文本文件支持 TXT、Markdown、日志、JSON、XML、CSV、INI、YAML 与常见代码/脚本格式，采用本地编码检测和分段读取。DOC/PPT、旧版 XLS、音视频、ZIP、文件夹等打开同一预览窗口，在中央显示不支持提示、文件位置及默认应用/资源管理器操作。图片预览工具栏可按需调用 Windows 本地 OCR；识别完成后可直接在图片上拖框选择文字，并复制所选或全部内容，不会在捕获或打开预览时自动识别。预览内 `↑/↓` 按列表顺序逐条切换记录（不支持的格式也会停留并显示说明），文字可用 `Ctrl+F`、`F3`、换行及行号，文档用 `←/→` 翻页、`Ctrl+滚轮` 或内容角落按钮缩放；表格用 `←/→` 切换工作表、滚轮或滚动条浏览，**表格不支持缩放**。`Space/Esc` 关闭。预览不会自动复制或粘贴。
- `Ctrl+A/C`：全选、复制记录；到目标输入位置手动 `Ctrl+V` 粘贴，搜索框中保持普通文字编辑行为。
- `Ctrl+F`：搜索；`Ctrl+Shift+A`：取消选择；`Ctrl+Shift+P`：置顶/取消置顶。
- 单击直接改选；`Ctrl+点击`：增减选择；`Shift+点击`：范围选择；`Ctrl+Shift+点击`：追加范围；鼠标按住拖移：连续多选。
- `Delete` / 顶部删除按钮：只删除选中项，无选择时不执行；行内按钮只处理本行。搜索栏右侧显示选中数量，右键选中记录可进行批量操作。
- `Ctrl+Z` / 顶部撤销按钮：撤销最近一批删除，支持本次运行内最近10批；搜索框内的Ctrl+Z仍撤销文字编辑。
- `Shift+F10` 或菜单键：打开记录右键菜单。清空全部是设置及列表空白菜单中的独立命令，需要确认。
- 关闭窗口会隐藏到托盘；左键单击托盘图标打开主界面，右键显示打开、暂停/继续、截图文件夹、设置和退出菜单。

默认点击已选中的单条记录保持选中；可在“设置 → 历史”开启“再次点击已选记录时取消选中”。开启后，再点唯一选中的记录会在松开鼠标时取消；按住拖选不受影响，多选时普通单击仍先收拢为一条。切到其他应用再回来也保留选择。双击、Enter 和 Ctrl+V 不执行记录操作；使用复制按钮或 Ctrl+C 取用记录。旧版的单选切换、多选点击模式和拖后点击恢复期设置字段保留兼容，但不再改变当前 Windows 选择规则。

## 功能

文字、文件和图片历史持久保存；保留原始文字空白和 Unicode，图片使用 PNG。记录去重、搜索（含拼音/首字母）、按全部/文字/文件/图片筛选、置顶、批量复制、快捷预览、截图目录监听、四种图标、系统/浅色/深色外观、五组选中颜色和自定义颜色、可选开机启动。

截图默认识别 Windows 的截图已知文件夹（支持重定向）。若目录尚不存在，请在设置中选择保存截图的位置。只导入启动监听之后新建或改名进入的图片；不会扫描导入旧截图。截图原文件继续保留。Win+Shift+S 复制的截图由普通剪贴板监听直接记录。

历史位于 `%LOCALAPPDATA%\ClipShelf\history.json`，设置位于同目录 `settings.json`，缓存图片位于 `images`。默认最多100条，优先保留置顶项。清空/删除只操作历史和应用自身缓存，不删除原文件。没有服务器同步，不上传剪贴板内容；遵守支持的剪贴板敏感内容排除标记。

当前开发版可在“设置 → 数据管理”把历史上限调整为 1–10000 条；调低后立即裁剪最旧未置顶记录并保存。主窗口退出时会记录位置，下次启动在原显示器恢复；显示器被移除、坐标异常或标题栏不可达时仍安全居中。启动尺寸策略保持不变。

## 1.3.x 文字预览、记录导航与文件取用

1.3.x 将剪贴板文字和常见文本文件统一到可选择、搜索的文字预览界面。文本文件在本地只读打开，检测 BOM、UTF-8、UTF-16 与 GB18030；大文件分段读取，不再只截取开头。可切换自动换行和行号，`Ctrl+F` 搜索、`F3` / `Shift+F3` 跳转，返回先前文件时恢复浏览状态。图片和原生 PDF / DOCX / PPTX 预览保持可用。

预览打开后，`↑/↓` 严格按主列表相邻记录移动，主列表选中框同步更新；不支持的格式也会停留并显示说明，不会跳过。文件即使最初是从资源管理器“剪切”进入剪贴板，也可作为文件记录保存；从 ClipShelf 再次复制该历史记录时只生成普通文件复制内容，不重放剪切标记，因此不会再次移动或删除原文件。1.3.4 的最终规则以此为准。

## 1.3.5 快速预览性能扩展

设置中的“预热相邻记录首屏”默认关闭。开启后，当前页和相邻页优先完成，随后以最低优先级准备列表前后各一条可预览记录；连续切换会取消旧任务，最多保留 3 个文档句柄。文本文件只检测编码并读取首段，不加载全文。

图片和分页文档可在预览内容区使用 `Ctrl+滚轮` 或角落按钮以 50%–400% 缩放；表格不支持缩放。缩放过程保留当前画面，停下约 220ms 后仅重新渲染最新目标的高清层，不改变窗口尺寸。页面缓存仍限制在 64 MiB / 24 项，优先保留当前文档的层级。基准命令现在自行生成样本，不会因缺失仓库外文件而报告空白通过；结果为引擎请求到位图的实测时间，不是实际显示 FPS。

## 1.2.x 交互与维护

1.2.x 收拢 Windows 版日常交互：优化列表普通滚动与多选滚动、将滚动条放到记录边框外的空白区域，并以贴近控件的 Fluent 提示取代旧式系统提示框。设置中提供手动清理可再生成缓存的入口；历史清理为独立选项，不会被普通缓存清理顺带执行。旧版本的发布与校验记录保存在 `docs/releases/`。

## 1.0.16 分文件记录与类型图标

新复制的多文件拆成独立记录，每条可单独复制、预览、置顶或删除。批量导入只排序、保存、通知一次，按路径去重并保留已有置顶与标识，遵守原历史条数上限。旧的合并记录暂不自动拆分。

使用 MIT 授权的微软 Fluent UI System Icons 矢量路径重做类型图标：PDF 红色、电子表格绿色、Word 蓝色、演示橙色、压缩包紫色、文件夹金色。未知文件回退到通用文档，浅深色分别配色；不在绘制时调用 Shell 或读取文件。授权见 ThirdPartyNotices.txt。

## 1.1.0 本地原生文档预览引擎（同时保留文字和图片）

PDF 使用 Windows 内置 PDF 引擎直接逐页渲染，不生成中间文件。DOCX/PPTX 直接读取本地 OOXML 内容，生成自己的页面场景并绘制，不调用 Office、LibreOffice 或 Windows Preview Handler。旧转换服务和辅助进程入口已删除。所有格式只读；不联网，不加载外部关系、远程字体、宏或嵌入程序。文字和图片依据用户后续要求保留：PNG、JPEG、BMP、GIF、TIFF、ICO（多帧显示首帧）；文字可选择，超过 100,000 字符明确提示截断，原记录不变。

架构分为 Provider、预览会话、后台 STA 调度器、OOXML 安全读取器、场景模型、DOCX 分页器和位图渲染器。打开的文档句柄最多保留 3 个；当前页优先，相邻页次之，增量总页数计算最低优先。DOCX 第一页不等待总页数；已完成的分页位置、剩余段落位置和场景保留为检查点。PPTX 遵循幻灯片关系顺序，读取内嵌缩略图后直接渲染目标幻灯片，不预先解析所有幻灯片。

缓存覆盖元数据、解析 XML 模型、DOCX 分页检查点/PPTX 场景和页面位图。位图最多 64 MiB / 24 项；模型缓存另有 64 MiB / 64 项上限。PNG 页面磁盘缓存位于 `%LOCALAPPDATA%\ClipShelf-PreviewCache\native-v1`，上限 512 MiB、14 天过期；临时写入后原子替换，写入失败不影响预览。键包含规范化绝对路径、大小、修改时间、头尾采样散列、Provider 版本、尺寸/DPI 档和质量等级。窗口关闭保留共享有效缓存；源文件变化时中止显示并提示重新加载。普通性能计时仅记录阶段及耗时，不含原文、文件名或路径。

DOCX 首版支持段落、标题和样式继承、基本字体属性、段落对齐/缩进/间距、列表、显式分页、页面边距、图片块、等宽基础表格、普通页眉页脚及中英文换行。PPTX 支持比例、纯色/基础渐变、母版和版式占位符、主题颜色/字体、文字框、图片裁剪、基础形状/旋转/透明度、层级和基础表格。界面明确显示“近似预览”：不是 Office 精确排版，DOCX 页数可能不同；复杂图表、SmartArt、组合/嵌入对象、公式等使用占位或降级提示。浮动图片按块排列，多节设置按末节近似，特殊编号和合并表格简化，超高表格行会明确提示只显示页内部分。动画、视频、3D、复杂艺术效果不执行。

安全边界：ZIP 最多 10,000 项、总声明展开量 256 MiB、单项 32 MiB；XML 最多 16 MiB、深度 64、300,000 节点、单值 200,000 字符。DOCX 正文 XML 当前会先整体安全读取，但段落解释和分页按需进行；这不是完全流式 XML 引擎。DOCX 最多 20,000 个正文块/1,000 页，PPTX 最多 1,000 张，嵌入图片最多 4,000 万源像素，高清页面位图最多 1,400 万像素。超限、损坏、加密、缺失关系、权限和文件删除均显示内容区错误，可重试、用默认应用打开或在资源管理器中显示。

固定外层、仅替换内容，保留上一帧并短淡入；遵循系统减少动画设置。PPTX 内嵌缩略图先显示，视口/DPI 稳定后按实际显示尺寸重新渲染。1.1.0 当时尚未实现相邻记录预热和任意倍率高清层；这两项已在 1.3.5 增加。首次 WPF/PDF 引擎初始化仍可能超过目标延迟，不承诺所有复杂文件的首屏时间。

构建目标更新为 Windows 10 2004+，推荐 Windows 11；使用微软 Windows SDK .NET 引用，独立包不需要用户安装 SDK。

## 1.0.14 设置滚轮跳变

设置页的单行输入框、快捷键框、未展开的下拉框与空白处使用同一条连续滚动路径，避免鼠标经过不同控件时退回系统逐行跳动；滚动也不会误改下拉设置。真正可滚动的内层视口与展开的下拉列表仍保留自身滚动。

较大的非标准滚轮增量不再被误判为可直接跳转的精细输入。细小增量接入进行中的滚动，不丢失原来的目标位置；独立细小输入仍保留原始距离。新增真实控件路由、跨控件连续滚动、混合增量与大增量回归检查。

## 1.0.13 设置连续性

修复点击开关后焦点回到顶部主题按钮、继而把页面滚回上方的问题。焦点修复现在恢复刚操作的设置控件，且不会强制滚动。设置页面在空闲时准备并复用；关闭重开保留本次运行内的滚动位置，文件夹与外部变化原地更新，不重建整页。

移除点击设置时的同步强制布局，遮罩与面板统一使用 140ms 缓出淡入，关闭可立即打断。开关圆点使用 110ms 小幅平移，连续切换从当前画面位置接续；遵守系统减少动画设置。这里的时间是过渡配置，不代表实际显示帧率。

设置专项测试覆盖四组开关连续切换、真实 WPF 焦点修复、滚动位置保留、缓存同步、未加载模板刷新与打开中途关闭。独立测试窗口 `--settings-demo <目录>` 使用合成配置，不连接用户剪贴板，F12 退出并记录无内容的焦点/滚动事件。

## 1.0.12 复制与预览职责分离

彻底移除自动粘贴：删除顶部、行内、右键菜单入口和 Enter/Ctrl+V 记录命令，同时移除外部目标窗口追踪及模拟按键。Space 不修改剪贴板、不隐藏或最小化主窗口。复制按钮和 Ctrl+C 保持当前窗口，随后由用户在目标应用手动 Ctrl+V。

隔离的复制/预览回归检查覆盖文字与图片预览、从按钮切回记录、待完成搜索、菜单命令和已编译程序中不存在自动粘贴机制。

以下为历史版本记录，其中自动粘贴相关描述已被 1.0.12 替代。

## 1.0.11 置顶图标与现代设置

记录行移除“已置顶”字样，置顶后直接将原来的大头针变为强调色，取消后恢复中性色；单选置顶记录时顶部大头针也同步变色。悬停提示及无障碍名称保留明确操作语义。

设置改为 Windows 11 风格的分组卡片、轻边线、紧凑图标选择和开关，标题与完成按钮固定，所有更改即时保存。“再次点击已选记录时取消选中”位于“历史与选择”。浅深色及所有现有选项保留。

设置滚轮使用按实际经过时间推进的连续滚动，精细输入直接响应；点击、键盘、隐藏及外部导航可中断。阴影与滚动内容分离，不把整页控件绘制到阴影效果表面。尊重系统减少动画设置，不固定为60帧；未将回调或截图当作实际显示FPS证明。

## 1.0.10 可选的再次点击取消选择

“设置 → 历史”新增“再次点击已选记录时取消选中”，默认关闭，切换立即保存，重启记住选择。只作用于不按修饰键再次点击唯一已选记录；不影响Ctrl/Shift、多选收拢、右键、行内操作及键盘导航。取消在同一行内松开时提交，开始拖选、滚轮、失去捕获或切换应用会取消待处理动作，避免拖选前出现空选择闪烁。

## 1.0.9 方向键选择不再显示外围蓝框

记录行不再绘制矩形焦点框。上下键改选和Shift连续选择只显示原有选中底色；Ctrl+方向键仅移动焦点、不改变选择时，未选中的焦点行使用左侧细灰色标记，选中后自动隐藏。按钮和设置控件保留Tab键盘提示。截图/鼠标焦点策略、选择规则、滚动和数据格式均不变。

## 1.0.8 Windows 图标比例与焦点提示

保留四款图标设计，去掉Mac原图多余的外圈透明安全区；窗口/任务栏、设置预览采用一致比例。安装图标补齐16–256像素的十档原生尺寸，避免小尺寸再缩整张大图。原始PNG和用户图标选项不变。

外围蓝框只随Tab、方向键等明确键盘导航显示，鼠标、截图快捷键、隐藏或切到其他应用时清除；正常选中记录的蓝色底纹仍保留。设置打开时焦点留在设置里，收到新截图或再次呼出主窗不再回到背景记录，关闭后返回原位置。

## 1.0.7 拖选闪烁修复

拖选由列表外层统一捕获鼠标，避免同时触发WPF列表自带的拖选与自动滚动，使选中范围在边缘滚动时反复被改写。保留普通、Ctrl/Shift选择规则、反向拖选、边缘自动滚动与拖选中滚轮；松手或失去捕获时停止拖选。布局、圆角、历史格式和粘贴/托盘行为不变。

## 1.0.6 粘贴与托盘修复

粘贴先准备剪贴板、核对目标窗口，再切回目标并发送Ctrl+V；不再隐藏ClipShelf，窗口和当前选择保留在后台及任务栏。未找到目标、目标被关闭、焦点切换失败或操作中剪贴板变化时明确提示，不再用“已粘贴”冒充目标应用已插入内容。使用前应先点击目标应用的输入位置，再打开ClipShelf选择记录；应用权限或编辑控件可能拒绝自动粘贴，此时可在目标位置手动Ctrl+V。

托盘单击立即打开，不再要求双击。右键复用主界面的Fluent菜单：8DIP浮层、4DIP行高亮、图标、细边、轻阴影、浅深色；只保留五项常用操作，不展开多行剪贴板正文，查看历史统一进入主界面。历史内容、快捷键和滚动实现不变。

## 1.0.5 统一 Windows 圆角层级

使用共享的8/4/0三档逻辑圆角：菜单、设置和下拉浮层为8；搜索框、历史列表容器、按钮、输入框、缩略图底板与选中标签为4；相邻记录及其焦点框为0，首尾由列表统一裁切。按钮的悬停与焦点轮廓沿用对应控件规则，缩略图内容也按底板裁切。外层窗口依然只由DWM管理，最大化及系统贴靠策略不变。

保留现有尺寸、边距、行高与滚动/选择实现，不修改历史格式或系统显示设置。圆角来自App.xaml中的ControlCorners、OverlayCorners和SquareCorners三个资源，避免每个控件单独出现5/7/9/10/12等不一致数值。

## 1.0.4 圆角、Fluent 菜单与连续滚动

窗口最外缘交由 Windows 11 的 DWM 单独绘制，不再叠加应用自画的12DIP圆角和边线；最大化使用系统方角，还原后恢复原生圆角。搜索、列表等内部面板保持原有布局。

选中数量移到搜索栏右侧的轻量标签，出现时不挤动搜索框。记录右键菜单改为Win11风格：8DIP圆角、细边框、轻阴影、统一图标、浅深色及圆角高亮；单条命令精简为复制/粘贴/预览，多选时明确显示条数。保留菜单的原生键盘行为。

鼠标滚轮保留细分输入量，普通刻度改为可中断的连续滚动；动画按实际经过时间推进，不写死60/160帧。改变方向、点击、键盘导航、拖选、设置或内容更新可以停止原有滚动。遵守系统滚动行数和减少动画设置，保留原生触控滚动与回收虚拟化。本机显示配置和DWM均约160Hz；测试中的渲染回调节奏不等于实际屏幕显示FPS。

## 1.0.3 Windows 交互适配

普通单击直接改选，Ctrl/Shift组合选择和拖选保持一致。键盘命令尊重搜索框、列表和按钮的焦点，不再将按钮上的 Enter/Space 抢作粘贴/预览。键盘操作显示实线焦点框，列表项向无障碍工具提供记录标题。

补充带文字及快捷键提示的右键菜单，批量命令明确显示选中数量。行内复制、粘贴、置顶、删除统一只作用于本行。删除与清空全部分离；撤销保留原内容、时间和置顶状态，图片缓存受保护。删除后新收到的记录优先保留；恢复时若达到容量上限，仅恢复剩余空间内的记录，不挤掉新内容。撤销仅保留在当前运行内，清空全部或退出后不再可用，不支持重做。

## 1.0.2 窗口缩放与边框修正

统一标题区、搜索框和列表左右18DIP边距及12DIP圆角。列表选中底色延伸至整行，滚动条覆盖显示不再留下空白槽，连续选中的行隐藏分隔线，取消默认列表焦点虚线。圆角遮罩在同次布局中复用更新，避免缩放时使用上一帧的边界。窗口改走DWM合成路径，避免每次拖动尺寸都重设旧式窗口区域并强制重绘；保持系统缩放/最大化及原有硬件加速。

## 1.0.1 流畅度优化

列表改为增量更新、像素滚动和容器复用；新记录进入时保留正在浏览的位置。拖选批量修改选择，指针停留同一行时不重复刷新。全文、拼音和模糊搜索在后台执行，快速输入会取消旧查询，不截断原始内容。

图片缩略图、预览和剪贴板图片处理移到后台；缩略图并发有上限且缓存按最近使用逐项淘汰。保存采用约50毫秒合并窗口和有序原子写入；正常退出会等待落盘，保存失败时暂缓退出并提示重试。强制结束进程或突然断电仍可能丢失最后尚未落盘的记录。无用图片缓存会在下次启动或正常退出时安全清理，原始文件始终保留。

性能记录与测试范围见 `PERFORMANCE.md`。这里的微基准不代表整机帧率或所有内容都达到同样倍数。

## Windows 差异

- 系统接管的三指触控板手势无法直接等同 macOS 三指拖移；使用鼠标拖选或触控板左键按住拖移。
- ClipShelf 只将记录复制到系统剪贴板；是否能粘贴取决于目标应用支持的格式。
- 多条图片可作为文件一起复制；混合文字/图片/文件时使用可读文本路径组合，接收应用能否识别由其支持的剪贴板格式决定。
- 快速预览支持文字记录、常见图片、PDF、DOCX、PPTX 及 XLSX/XLSM 表格；无需安装 Office。旧 DOC/PPT/XLS 不进入快速预览。Office 文档和表格均为近似预览，未移植 macOS 第三方预览器。
- 原仓库 Releases 是 Mac 安装包，目前没有 Windows 在线自动更新源，因此不会把 Mac 下载包显示为 Windows 更新。

## 构建与验证

需要 .NET8 SDK，WPF 项目不依赖第三方 NuGet 库。运行 `build.ps1 -SelfContained` 构建 Windows x64独立包。`build.ps1 -SelfContained -Test` 运行真实剪贴板测试（请先暂停其他剪贴板工具，避免保存测试内容）。

`ClipShelf.exe --self-test --test-report <绝对路径>` 使用隔离临时目录验证存储、剪贴板、图片透明通道、截图监听和快捷键冲突，并尝试恢复测试前的剪贴板。`--copy-only-test <目录>` 验证文字/图片预览和旧粘贴命令已移除，不写入真实剪贴板。`--file-preview-test <目录>` 验证格式、缓存、分页、取消、过期结果、错误和浅深色/DPI 渲染。`--native-preview-test <目录>`（兼容别名 `--preview-interaction-test`）直接生成合成 OOXML 样本，验证原生排版、幻灯片顺序、样式、安全限制、预热取消、缩放层和键盘；不调用 Office。`--native-preview-benchmark <目录>` 自行生成合成样本，报告冷/热页时间及同一次运行内预热关闭/开启的对照。`--preview-scroll-test <报告.json>` 在后台预热及高清渲染期间测试主列表滚动。DPI 截图为渲染模拟，滚动回调也不等同于物理多显示器或真实显示帧率验收。

`ClipShelf.exe --render-qa <输出目录>` 使用独立示例数据渲染浅色、深色和设置面板。示例不进入日常历史。设计与功能对照见 `PARITY.md`。

`ClipShelf.exe --ui-performance-test <报告路径>` 使用1000条合成记录检查滚动、拖选、选择保留及搜索竞态，不读取剪贴板。`ClipShelf.exe --quit` 请求正常退出当前实例，等待未完成保存。

`ClipShelf.exe --layout-test <报告目录>` 检查边距、圆角、选中接缝、不同大小及高DPI栅格输出，另检查缩放期间的DWM窗口区域；不读取剪贴板和日常历史。

`ClipShelf.exe --interaction-test <报告路径>` 用独立合成数据检查 Windows 选择、键盘命令作用域、菜单及撤销删除，不读取日常历史或真实剪贴板。

`ClipShelf.exe --presentation-test <报告目录>` 检查选中标签和浅深色菜单布局并输出图片。`ClipShelf.exe --scroll-render-test <报告路径>` 会短暂显示1000条合成记录的自动滚动窗口，检查时间步、输入比例、取消、真实列表偏移及回调间隔；不注入系统输入、不访问真实剪贴板，也不将回调率称为实显FPS。

经过筛选的历史发布校验、性能基线和通用安装验证脚本见 [`docs/README.md`](docs/README.md)。这些资料不包含用户历史、设置、缓存或本机安装结果；临时测试输出继续写入被 Git 忽略的 `artifacts/`。
