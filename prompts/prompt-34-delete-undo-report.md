# prompt-34 删除可撤销 - 实施报告

## 结果

删除单条、批量删除和清空历史现在都会进入本次运行内的撤销栈。用户可通过工具栏撤销按钮或 `Command-Z` 恢复最近一批，最多保留 10 批，不支持重做。恢复保留原记录的 ID、时间和置顶状态，并且只使用当前历史上限内的剩余空间，不会挤掉删除后新增的记录。

搜索框聚焦时，`Command-Z` 会继续交给系统文字编辑，不触发历史撤销；现有 `Command-A/C/V` 行为未改动。

## 改动文件

- `Sources/ClipShelfLite/Support/HistoryDeletionUndo.swift`
  - 新增包含原始索引的批次撤销栈，容量固定为 10。
- `Sources/ClipShelfLite/Stores/ClipStore.swift`
  - 删除与清空时记录批次；增加撤销状态和恢复入口。
- `Sources/ClipShelfLite/Views/MainView.swift`
  - 增加工具栏撤销按钮和 `Command-Z`；搜索框聚焦时放行系统撤销。
- `Sources/ClipShelfLite/Support/SelfTest.swift`
  - 增加顺序/元数据、10 批上限、历史容量和清空恢复断言。
- `README.md`
  - 中英文功能列表补充删除撤销。

## 手工验证步骤

1. 选中 3 条记录删除，点击工具栏撤销，确认 3 条全部恢复且顺序、时间和置顶状态不变。
2. 删除一条后复制新内容直至达到历史上限，再撤销，确认新内容不会被挤掉。
3. 在设置中清空历史，回到主界面按 `Command-Z`，确认整批恢复。
4. 连续删除 11 批，确认最多只能撤销最近 10 批。
5. 撤销栈为空时确认按钮淡显且不可点击。
6. 在搜索框输入文字、删除部分文字后按 `Command-Z`，确认只撤销搜索文字编辑，不恢复历史记录。
7. 验证 Delete 键、工具栏删除、行内删除和设置中的清空入口仍保持原有删除范围。

## 范围说明

- 撤销栈不持久化，应用重启后为空。
- 未修改 `history.json` 格式。
- 未增加重做功能。
